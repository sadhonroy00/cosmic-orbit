# 🌌 Cosmic Orbit — Interactive Solar System

A mobile-friendly, interactive solar system simulation with a galaxy-inspired background.

## Features
- ☀️ Sun + all 8 planets with animated orbits
- 🌌 Starfield and nebula-style space background
- 🪐 Tap planet buttons or planets to see key facts
- ⏯ Pause/play, simulation speed, zoom, orbit and label controls
- 📱 Responsive layout for phones and desktops
- ⚡ Pure HTML, CSS and JavaScript — no build tools

## Run
Open `index.html` in a modern browser.

## GitHub Pages
1. Upload `index.html` to a repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. Wait for the published site link to appear.

## Note
Orbital spacing and planet sizes are visualized for a pleasing overview and are not to scale. Orbital motion is an illustrative simulation, not a live astronomical ephemeris.
